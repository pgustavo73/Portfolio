# Portfolio

Source for my personal portfolio site, published with GitHub Pages at:

**https://pgustavo73.github.io/Portfolio/**

Plain static HTML/CSS/JS — no build step, no framework.

- `index.html` — page markup (About, Skills, Projects, Contact)
- `styles.css` — styling (dark theme)
- `script.js` — mobile nav, scroll reveal, active-link highlighting
- `.nojekyll` — tells GitHub Pages to serve the files as-is (skip Jekyll processing)

## Local preview

```
python3 -m http.server
```

Then open `http://localhost:8000`.
